# Convención de nombres --- Certificaciones del portafolio

Este documento registra la convención de nombres utilizada para las
carpetas y archivos de certificaciones del portafolio.

## Convención general

-   Usar minúsculas.
-   No usar acentos ni `ñ`.
-   No usar espacios.
-   Separar palabras mediante guiones (`-`).
-   Evitar caracteres especiales.
-   Conservar la extensión real del archivo hasta realizar una
    conversión de formato.
-   Para DC-3 utilizar `dc3-anverso` y `dc3-reverso`.
